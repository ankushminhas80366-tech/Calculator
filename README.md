# Calculator

A simple command-line calculator written in Python.

## Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`), with a check that prevents dividing by zero
- Input validation for numbers and operations
- Type `exit` to quit

## Requirements

- Python 3

## How to run

```bash
python main.py
```

## Usage

1. Start the program.
2. Enter an operation: `+`, `-`, `*`, or `/`.
3. Enter the first number, then the second number.
4. The result is printed.
5. Repeat, or type `exit` to quit.

Example session:

```text
Simple Calculator
Operations: +, -, *, /
Type 'exit' to quit.

Enter operation (+, -, *, /) or 'exit': +
Enter first number: 12
Enter second number: 5
Result: 17.0
```

## Project structure

- `main.py` — calculator functions and the interactive loop
